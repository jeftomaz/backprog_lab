# Backprop Lab

## Contexto

Laboratório estático em português para praticar forward propagation e backpropagation em uma rede com uma camada oculta.

## Stack

HTML, CSS e JavaScript sem dependências ou backend.

## Regras

- Entradas, alvos e pesos são a fonte única dos dados conhecidos.
- Resultados validados alimentam as fórmulas seguintes.
- Publicação via GitHub Pages a partir da branch `main`.
