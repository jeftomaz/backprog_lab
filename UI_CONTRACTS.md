# Contratos de interface

| Elemento | Regra |
| --- | --- |
| Ícone `?` | Abre explicação central sem alterar o valor associado. |
| Preparação | Único local editável; reúne arquitetura, entradas, alvos e matrizes de pesos. |
| Prática | Exibe uma etapa por vez e mantém apenas a ação útil para o estado atual habilitada. |
| Diagrama e inspetor | Apenas consultivos; nós aceitam clique, `Enter` e espaço. |
| Caderno | Única visão consolidada; exibe apenas resultados aceitos ou revelados. |
| Fórmula | Usa texto puro, símbolos gregos e substituição automática. |
| Foco | Na prática, acompanha o cálculo; fora dela, clicar fora do nó remove o foco manual. |
| Alteração ativa | A Preparação avisa que editar dados reinicia o progresso. |
